### 我做过的小东西

都是从自己的日常需求出发，慢慢做出来的小工具。按用途放在下面，感兴趣的话可以点进仓库看看 👇

#### 🎨 创作与文档

- [**四季画布 · FourJ Canvas**](https://github.com/deepfry666/fourj-canvas)  
  把无限画布、AI 图片与视频生成、素材管理放在一个桌面工作区里。当前安装包面向 **Windows x64**，AI 服务需要自行配置。基于 [infinite-canvas](https://github.com/basketikun/infinite-canvas) 独立维护。
- [**软件指南生成器**](https://github.com/deepfry666/manual-studio)  
  输入软件名，生成界面示意、说明文字和 Word / PDF / TXT 等文档。面向 **macOS**，目前维护的是 SwiftUI 原生版，Electron 旧版只留作对照。

#### ☀️ 光伏绘图

- [**四季光伏工具箱**](https://github.com/deepfry666/fourj-pv-toolbox)  
  画光伏结构图时用的 AutoCAD 插件，可以自动画导轨、布置和统计配重、翻译图纸文字。目前验证范围是 **AutoCAD 2020 Win64 R23.1**。

#### 📊 账户与出口监控

- [**上游账户监控**](https://github.com/deepfry666/cpa-upstream-account-monitor)  
  给 **CLIProxyAPI / CPA Manager Plus** 用的小工具，在一页里看上游账户的余额、周期额度、用量和健康状态。不同账户、币种和额度窗口分开展示，查不到的数据保留为未知。
- [**Mihomo 监控**](https://github.com/deepfry666/cpa-mihomo-monitor)  
  看 **Mihomo** 当前出口、活动连接和订阅节点状态，也能手动切换允许操作的代理组。可以独立使用，也可以通过入口插件放进 CPA 菜单。

安装方式、使用限制和最新版本，以各仓库的 README 与 Releases 为准。

有问题或者建议，欢迎到对应项目开个 Issue 告诉我 🙌
